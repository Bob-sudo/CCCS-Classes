This is a closed-book, no C++ compiler, 6-minute quiz.

%------------------------------------------------------------------------------
The following questions relate to bubblesorting the following array of integers:
\begin{center}
\verb!5       1       8       3       7       9!
\end{center}

%------------------------------------------------------------------------------
\nextq
How many comparisons are carried out in the first pass?
(i.e. how many times the $< $ or $\leq$ or $>$ or $\geq$
comparison was executed in the first pass.)
\\
\ANSWER
\begin{answercode}
5
\end{answercode}

%------------------------------------------------------------------------------
\nextq
How many swaps are carried out in the first pass?
\\
\ANSWER
\begin{answercode}
3
\end{answercode}

%------------------------------------------------------------------------------
\nextq
What are the values in the array at the end of the first pass?
Write it in this form: \verb!{1, 2, 3, 4}!.
This is not the right answer -- it's just to provide a format for the answer.
\\
\ANSWER
\begin{answercode}
{1, 5, 3, 7, 8, 9}
\end{answercode}

%------------------------------------------------------------------------------
\nextq
What are the values in the array at the end of the second pass?
Write it in this form: \verb!{1, 2, 3, 4}!.
This is not the right answer -- it's just to provide a format for the answer.
\\
\ANSWER
\begin{answercode}
{1, 3, 5, 7, 8, 9}
\end{answercode}

%------------------------------------------------------------------------------
The following are the values in a sorted array of integers:
\begin{center}
\verb!1       3       5       7       8       9!
\end{center}
The following are questions related to the binary search algorithm.
The index variables are \verb!lower!, \verb!upper!, and \verb!mid!.
Of course \verb!lower! is initialized to $0$ and \verb!upper! is initialized to
$5$ and during the search, the first value assigned to \verb!mid! is $2$.

%------------------------------------------------------------------------------
\nextq
If the binary search is executed with the aim to find the value $7$,
during the first iteration, which variable (\verb!lower! or \verb!upper!)
is changed?
\\
\ANSWER
\begin{answercode}
lower
\end{answercode}

%------------------------------------------------------------------------------
\nextq
Continuing the above question, what is the new value of the variable that
was changed in the above question?
\\
\ANSWER
\begin{answercode}
3
\end{answercode}

%------------------------------------------------------------------------------
\nextq
Write down all the values of \verb!mid! during the binary search
for \verb!1! in the above array.
Write it in this form: \verb!1 2 3 4!.
This is not the right answer -- it's just to provide a format for the answer.
\\
\ANSWER
\begin{answercode}
2 0
\end{answercode}

%------------------------------------------------------------------------------
\nextq
Write down all the values of \verb!mid! during the binary search
for \verb!6! in the above array.
Write it in this form: \verb!1 2 3 4!.
This is not the right answer -- it's just to provide a format for the answer.
\\
\ANSWER
\begin{answercode}
2 4 3
\end{answercode}
