\nextq
Write a function \verb!replace()! that
on calling \verb!replace(x, y, z)!,
replaces every occurrence
of string \verb!y! in string \verb!x! with string \verb!z!.
For instance the output of
\begin{console}[fontsize=\small]
char x[1024] = "hello world hello missouri hello columbia";
char y[1024] = "hello";
char z[1024] = "goodbye";
replace(x, y, z);
std::cout << x << '\n';
\end{console}
is
\begin{console}[fontsize=\small]
goodbye world goodbye missouri goodbye columbia
\end{console}
Note that if \verb!x! is \verb!"aaa"!, \verb!y! is \verb!"aa"!,
and \verb!z! is \verb!"A"!, then after called \verb!replace()!,
\verb!x! is \verb!"Aa"!.
You must \textit{not} use any string function/method provided by C/\cpp.
\\
\ANSWER
\begin{answercode}
#include <iostream>

void replace(char * x, const char * y, const char * z)
{
}

int main()
{
    char x[1024], y[1024], z[1024];
    std::cin >> x >> y >> z;
    replace(x, y, z);
    std::cout << '[' << x << "]\n";
    return 0;
}
\end{answercode}

(Hint: For each \verb!i!, you want to check if starting with \verb!x[i]!
you can see the characters of \verb!y!, i.e.,
\verb!x[i]! is \verb!y[0]!,
\verb!x[i+1]! is \verb!y[1]!,
etc.
This part finds the \verb!y! inside your \verb!x!.
If so, then you do a replacement of \verb!y! inside \verb!x! with \verb!z!,
starting at \verb!i!.
You want to consider two cases:
when length of \verb!y! is $\geq$ the length of \verb!z!
and
when length of \verb!y! is $<$ the
length of \verb!z!.
It's probably a good idea to write several helper functions.)
