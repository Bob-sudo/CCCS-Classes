\vspace{-2mm}
\begin{Verbatim}[frame=single,fontsize=\small]
// Selects the index of a pivot in x[start .. end - 1]

// Performs a partition algorithm on x[start .. end - 1] with the pivot at

int partition(int x[], int start, int end, int i);
\end{Verbatim}
\vspace{-4mm}
Complete the quicksort below.

\ANSWER
\begin{answercode}
void quicksort(int x[], int start, int end)
{ 
    if(end - start <= 1)
      return;
      
    int pivotindex = pivot_index(x, start, end);
    int pivotfinal = partition(x, start, end, pivotindex);

    quicksort(x, start, pivotfinal);
    quicksort(x, pivotfinal + 1, end);
}
\end{answercode}

Complete the following sorting function.

\ANSWER

(a) \textsc{Explanation:}\vspace{-3mm}
\begin{answerlong}
To sort this array I want to implement a counting sort algorithm. In a for-loop: to handle the decimals I will multiply each element of the array by 10 and add 20 to handle negatives, I will change these values back later with another for-loop. This will give me a count range from 0 to 40. Create a loop that puts the number of times each value occurs to the corresponding index in count. Then, make a value int j, int i, and double k all set to 0. In a double for-loop, iterate i until it reaches 40 (our range), on the inner-loop, k will stop when it is greater than count[i]. Within this loop, x[j] will equal i. After sorting through the entire array, convert back to a range of -2.0 to 2.0. The runtime for this should be O(n + k), with memory needed being O(k), k being the range of numbers.
\end{answerlong}

(b) \textsc{Implementation:}\vspace{-2mm}

void sort(double x[], int n)
{
  for(int i = 0; i < n; i++)
  {
    x[i] *= 10;
    x[i] += 20;
  }
  
  double count[40] = { 0.0 };
  for(int i = 0; i < n; i++)
  {
    count[x[i]]++;
  }
  int j = 0;
  for(int i = 0; i < 40; i++)
  {
    for(double k = 0.0; k < count[i]; k++)
    {
      x[j] = double(i);
      j++;
    }
  }

   for(int i = 0; i < n; i++)
  {
    x[i] -= 20;

int t[1000000000]; // Temporary array that can be used by merge()

// Performs the merge operation on x[start0 .. end0 - 1] and
// x[start1 .. end1 - 1]. Here start1 = end0. You can assume the left and right
// subarray can fit into the above temporary array t.
void merge(int x[], int start0, int end0, int start1, int end1)
{
  int left = start0, right = start1, k = 0;

  while(left < end0 && right < end1)
  {
    if(x[left] < x[right])
      t[k++] = x[left++];
    else
      t[k++] = x[right++];
  }

  while(left < end0)
     t[k++] = x[left++];
  while(right < end1)
     t[k++] = x[right++];

  for(int i = 0; i < k; i++)
  {
    x[start + i] = t[i];
  }
}

void mergesort(int x[], int start, int end)
{
  if(end - start <= 1)
    return;

\textsc{Explanation}:
\begin{answerlong}

I would make a temporary vector array called it t. I will created two separate for loops, with the first loop putting all even indexed values into t, and the second doing the same but for odd indexed values. Move this semi-sorted array back into x and empty out t. Now, perform a merge of the even and odd portions. I will need an even and odd index for this, as well as a index for t, call it k. Put the lesser element of the two even & odd indexes into t and repeat until either index has to stop. Use two while-loops to place any remaining elements into t from either the even or odd index. Last, copy everything from t back into x.

\end{answerlong}

void sort(std::vector< int > & x, int n)
{
    std::vector< int > t(n);

    //fill t with even indexed values first
    int j = 0;
    for(int i = 0; i < n; i = i + 2)
    {
      t[j] = x[i];
      j++
    }
    //fill t with odd indexed values
    for(int i = 1; i < n; i = i + 2)
    {
      t[j] = x[i];
      j++;
    }

      x[i] = t[i];
