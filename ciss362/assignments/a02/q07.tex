Induction Step: We will now prove the inductive case

2^k > k^2, for k >= 4

Our object is to prove that

2^(k+1) >= (k + 1)^2

So,

2^(k+1) = 2*2k^2 >= 2k^2 >= (k + 1)^2

Hence, P(k + 1) holds

Therefore, by weak mathematical induction, P(n) is true for all n >= 4.
